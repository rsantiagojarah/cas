## Reglas para el desarrollo de código

- El código debe ser **escalable**, **mantenible** y escrito con **buenas prácticas**.
- Debe ser **fácil de entender y modificar** por otros desarrolladores.
- El lenguaje a utilizar es **Python**.
- Es obligatorio aplicar los principios **SOLID** y **DRY**.
- El desarrollo debe seguir **estrictamente** el documento de diseño proporcionado.
- Los nombres de las variables, funciones, clases y métodos deben ser **descriptivos** y **concisos**.
- Tener en cuenta la **legibilidad** del código, para que sea fácil de entender y modificar por otros desarrolladores.
- Las lineas de codigo deben tener un maximo de 150 caracteres.
- Cada archivo debe tener un maximo de 200 lineas de codigo
